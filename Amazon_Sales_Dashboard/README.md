# Power BI Sales Dashboard

A basic interactive sales dashboard developed using Microsoft Power BI to explore sales performance across categories, markets, countries, cities and shipping modes.

## Project Overview

This project uses an Orders dataset to create an interactive dashboard for basic sales analysis and reporting.

## Key Features

* Sales, Profit, Quantity and Shipping Cost KPI cards
* Category and Market slicers for interactive filtering
* Sales analysis by country, city, market and shipping mode
* Interactive charts and visualizations
* Country-level sales analysis
* Basic dashboard-based data reporting

## Tools Used

* Microsoft Power BI
* Data Analysis
* Data Visualization
* Dashboard Creation
* KPI Reporting
* Interactive Filtering
